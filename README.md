# Endless Match

A memory matching game built with React and Tailwind CSS. Match pairs of colored shapes before time runs out!

## Features
- Progressive scoring system
- Combo multipliers
- Time bonuses for streaks
- Mobile responsive design

## Installation
```bash
npm install
npm run dev
